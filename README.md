# Jogo da Forca

Versão web do clássico jogo da forca, desenvolvida com React e Vite.

O objetivo é descobrir a palavra secreta letra por letra. A cada erro, uma parte do boneco é desenhada. Com 6 erros, o jogador perde. Se completar a palavra antes disso, vence.

## Demo

[https://react-hagman.vercel.app](https://react-hagman.vercel.app)

## Funcionalidades

- Sorteio aleatório de palavras
- Teclado virtual com letras do alfabeto
- Feedback visual de acerto e erro
- Contagem de tentativas com imagens da forca
- Interface responsiva e simples de jogar

## Tecnologias

- React
- Vite
- Styled Components
- Context API
- Vercel
